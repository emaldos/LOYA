Terminal

A resizable terminal panel docked to the right edge of the window, offering shell sessions (your login shell, PowerShell, or CMD on Windows) with optional elevation.

Unlocks resizing and interactive full-screen tools. If a session fails to start this way it falls back to the current method automatically, so turning it on cannot break the terminal.

Controls what happens when you click a row on the Snippets and Commands pages, and how much confirmation a run needs before it reaches a shell.

Full terminal mode is a real terminal emulator: full-screen programs such as vim, htop, less, ssh and AI CLIs draw and take keys as in a desktop terminal, but there are no command blocks or job tracking. Any tab can be switched from its tab menu or the right-click Session menu. Claude Code and Codex CLI tabs always use it.

A command counts as risky when it is marked destructive, still contains unresolved {PLACEHOLDER} values, asks for elevation, or matches a known destructive pattern.

Terminal Suggestions and Shortcuts

While you type at the terminal prompt, matching commands from the Commands page appear above the cursor. Tab or Right accepts one, Up and Down choose, Esc dismisses. Nothing runs until you press Enter, and {PLACEHOLDER} values are filled from the live target where possible.

Click a box and press the new key combination. Backspace clears it, Esc cancels. Use Ctrl or Alt with a key, or F1-F12. Keys the shell or the app already use (Ctrl+C, D, Z, L, R, U, W, A, E, F, K, V, Ctrl+Tab, Ctrl+1-9) and desktop keys such as Ctrl+Alt+T are refused.

Terminal Profiles

Saved session presets: a shell, a starting folder, environment variables and an optional startup command. Detected WSL distributions appear in the shell list automatically.
